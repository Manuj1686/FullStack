# MR Fintech — White & Blue Premium UI

The frontend has been restyled to match the approved clean white-and-blue reference: spacious layout, royal-blue accents, subtle glass surfaces, soft shadows, and restrained gradients. The overview intentionally shows only three summary cards and two charts; detailed transactions and budget controls remain in their dedicated navigation views.

Branding is updated to **MR Fintech** throughout the main interface. The sidebar credits **Manuj & Rudransh** without surnames.

The React/Vite frontend and Spring Boot/MongoDB backend structure and API integration are retained. Run instructions are in `README.md`.

Build validation was not completed in this environment because installing the frontend dependencies timed out. Run `npm install` followed by `npm run build` in the `frontend` directory on your machine.
